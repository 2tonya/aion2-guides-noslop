# Aion 2 — PvE-гайды по классам (noslop)

Компактные мобильные PvE-гайды по **Aion 2** для всех 8 классов в одном месте. На русском языке, названия скиллов сохранены на английском.

**Сайт:** https://2tonya.github.io/aion2-guides-noslop/

**Оригинал:** https://2tonya.github.io/aion2-guides/

## Классы

- **Лучник (Ranger)** — DPS
- **Ассасин (Assassin)** — DPS
- **Чародей (Sorcerer)** — DPS
- **Заклинатель (Spiritmaster)** — DPS
- **Страж (Templar)** — Танк
- **Гладиатор (Gladiator)** — DPS
- **Клирик (Cleric)** — Хил
- **Чантер (Chanter)** — Саппорт

## Что внутри гайдов

- **Путь: от новичка до топа** — приоритеты по этапам (P1–P4): что качать и собирать в первую очередь.
- **Порядок прокачки скиллов и пассивок** (приоритеты) + **Specialty/стигмы**.
- **Макросы и ротации**, экипировка/Arcana (по слотам, с опорой на доступные данные источников).
- **Доски Дэваниона**, частые ошибки и прочие заметки по классу.
- Скриншоты, иконки скиллов и авторство/источники в каждом гайде.

## Возможности сайта

- **Одностраничный интерфейс** с переключением классов и разделов (чипы), подсветка активного раздела при прокрутке.
- **«Быстрый старт» (P1)** в начале каждого гайда — краткая выжимка и ключевые советы, плюс отметка актуальности/источник.
- **Меню A2**: выбор класса (с меткой роли), выбор темы, переход в глоссарий.
- **Темы**: Системная, Тёмная, Светлая, Тыквенная, Голубая.
- **Поиск** по гайдам и глоссарию (по словам) с переходом к нужному разделу/термину и подсветкой совпадений.
- **Глоссарий и справка** (Системы, Бой, Характеристики, **Сравнение классов**, **FAQ**) — доступны через меню A2; термины в гайдах кликабельны и ведут в глоссарий, с кнопкой возврата в место перехода и подсветкой термина.
- **PWA**: установка и базовая офлайн-работа (кэширование ядра и ассетов).
- Удобно на мобильных устройствах.

## Локальный запуск

Сайт статический — можно открыть `index.html` напрямую, но для корректной работы рекомендуется локальный сервер:

```bash
git clone https://github.com/2tonya/aion2-guides.git
cd aion2-guides
python -m http.server 8080
# или
npx serve .
```

После запуска открыть http://localhost:8080

## Структура репозитория

```text
.
├─ index.html            # страница, контент гайдов и глоссария
├─ assets/
│  ├─ style.css          # стили и темы
│  └─ app.js             # логика UI, навигация, поиск, глоссарий, темы, PWA-регистрация
├─ img/                  # иконки классов/скиллов, скриншоты, доски, PWA-иконки
├─ manifest.webmanifest  # PWA-манифест
├─ sw.js                 # service worker
└─ README.md
```


## Скиллы и анти-AI-slop доработки

Это отдельная копия проекта, в которой дизайн и UI доработаны с опорой на популярные frontend/design-скиллы (найдены на GitHub):

- **[anthropics/skills — frontend-design](https://github.com/anthropics/skills)** (репозиторий ~192k★) — осознанный визуальный дизайн, привязка к предмету, уход от шаблонных решений.
- **[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)** (~113k★) — «вкус» и качество frontend-исполнения, анти-slop подход.
- **[funboy322/avoid-ai-design](https://github.com/funboy322/avoid-ai-design)** — аудит и устранение типичных AI-slop паттернов (в т.ч. шаблонный chrome, декоративные акценты, проблемы фокуса и др.).

Скиллы были установлены в рабочую сессию и применены к копии: упрощён визуальный шум (лишние blur/декоративные акценты, шаблонные ALL-CAPS/разделители), усилена доступность (видимый `:focus-visible`), сохранены контент, структура и функциональность исходного сайта.
